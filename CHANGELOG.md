# Журнал изменений

## Локальные доработки форка

- Добавлен `econlauncher` — графический лаунчер на raylib для подключения к серверу
  или запуска локального сервера.
- Лаунчер проверяет, запущен ли локальный сервер на выбранном порту, и не создаёт
  повторный процесс. После нового запуска он ожидает готовности сервера перед
  открытием клиента.
- Убрана консоль у `econspace`, `worldeditor` и `econlauncher` в Windows-сборках.
  Консоль оставлена у `econserver`, поскольку она показывает состояние сервера.
- Нажатие Escape больше не закрывает окна игры и редактора. В игре Escape открывает
  меню паузы с возвратом в игру или выходом из клиента.
- Меню паузы затемняет только игровое окно на 50% и использует прозрачные кнопки с
  белой рамкой.
- Лаунчер использует собственную тёмную верхнюю панель с кнопкой закрытия, без
  стандартной светлой системной полосы.
- CMake копирует необходимые MinGW runtime DLL рядом с исполняемыми файлами, чтобы
  их можно было запускать из Проводника Windows без установленной среды MSYS2.
